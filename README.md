# E-Commerce Frontend

Frontend of an e-commerce application built with HTML, CSS, and JavaScript.

## 🚀 Features

- Responsive Design
- User Login
- Product Catalog
- Shopping Cart
- Product Search
- Protected Pages
- Clean UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## 📁 Project Structure

```
assets/
pages/
script/
```

## ▶️ Running

Clone the repository:

```bash
git clone https://github.com/Aizenn835/ecommerce-frontend.git
```

Open the project using VS Code and run it using Live Server or your preferred web server.
